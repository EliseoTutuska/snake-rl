# 从表格 Q 到掩码 DQN：8×8 贪吃蛇的迭代式强化学习实验

**技术报告** · 项目 `snake-rl` · 训练设备 Mac CPU · 2026

---

## 摘要

本文记录在固定规则的 8×8 贪吃蛇上，用同一套 Gym 风格环境反复替换「智能体看见什么、允许走哪、即时奖励是什么」的实验过程。动作空间始终是三个相对动作（直行 / 右转 / 左转），不使用 PPO 或 GAE。主要结论有三条。

第一，**观测决定天花板**。11 维 0/1 特征把局面压成约 256 个状态，表格 Q-learning 的近 50 局均分稳定在约 12，再增加局数无效。换成朝向朝上的网格卷积后，均分进入 16–21。

第二，**搜索边界往往比优化器更重要**。在网格 DQN 上加入一步死亡掩码后，撞墙从数千次降到数百；若掩码在「全不安全」时改回全合法，墙死会重新占到约四分之一。修掉该兜底后，撞墙在数百局内接近 0。

第三，**长蛇是几何问题，不是优势函数问题**。长度 ≥ 20 后用曼哈顿靠近食物，均分卡在约 21；改成「安全 BFS 吃豆，否则沿尾巴走」后，开局启发式探测均分约 35，看板在 793 局、\(\varepsilon\) 仍为 0.69 时近 50 局均分 **36.34**，死因约 94% 为超时。8×8 满盘为 61 分，当前瓶颈是活着却吃不满，继续降 \(\varepsilon\) 预期不会再上一个大台阶。

全文数字来自本仓库的命令行自检（`python -m server.train_cli`，固定 `seed=1`）与 Vue 看板一次运行的快照。看板无法固定种子，仅作对照，不作严格复现声明。

## 1 引言

贪吃蛇是确定性、完全可观测的格子游戏：蛇每步移动一格，吃到食物则身体增长，撞墙或撞到自身则结束。8×8 棋盘共 64 格，开局长度 3，**理论满分 61**（占满棋盘）。分数定义为本局吃到的食物数。

该任务对强化学习有两个教学价值。其一，即时奖励可以写得很密（吃豆、死亡），但真正难的是**长蛇的空间规划**：必须给尾巴留出路，而不能只朝食物走。其二，失败模式可计数（撞墙 / 撞自己 / 超时），比单独看均分更能说明算法改在了哪一层。

本项目的工程约束是刻意收窄的：

- Python 是环境与训练的真相源；训练循环在进程内调用 `env.step()`，不经过 HTTP。
- Vue 只做人玩、看板与 WebSocket 快照。人玩 10×10，训练与观看固定 8×8（卷积输入尺寸绑死）。
- 设备为 Mac CPU；不使用 GPU，不上 PPO / GAE。

问题因此不是「哪篇算法论文的默认超参最好」，而是：**在同一环境上，每改一层表示或约束，失败分布如何变化。**

## 2 预备：环境作为马尔可夫决策过程

记状态为 \(s\)，动作为 \(a\)，即时奖励为 \(r\)，折扣因子为 \(\gamma\)。环境转移几乎确定：给定蛇身、朝向、食物与动作，下一格唯一。

**动作。** 智能体输出相对当前朝向的离散动作 \(a \in \{0,1,2\}\)。相对动作自动禁止 180° 掉头，避免「一步倒车咬到第二节」。人玩的方向键先经 `abs_to_rel` 映射到该空间。

**回报与价值。** 学习目标是最大化折扣回报 \(G_t = \sum_{k=0}^{T} \gamma^k r_{t+k}\)。表格方法与 DQN 都估计动作价值 \(Q(s,a)\)，贪心策略为 \(\arg\max_a Q(s,a)\)。本文不训练状态价值 \(V(s)\)，因此也不需要 GAE。

**奖励事件。** 环境产生符号事件，再由独立模块映射为标量（便于改塑形而不改碰撞）：

| 事件 | 典型标量 | 含义 |
|---|---|---|
| `eat` | \(+10\) | 吃到食物 |
| `wall` / `self` | \(-10\) | 撞墙或撞自己 |
| `timeout` | \(-4\)（后期） | 连续多步未吃到 |
| `move` | 靠近食物 \(\pm 0.05\) 等 | 塑形 |
| `win` | \(+10+50\) | 占满棋盘 |

**超时。** 连续若干步未吃到则结束。早期为 \(2n^2\) 步，后期改为 \(4n^2\)（8×8 上为 256），以便长蛇绕路。

## 3 系统设置

训练线程持有独立的 `SnakeEnv` 与 `DqnAgent`。约每 80 ms 或每局结束通过 WebSocket 推送局数、近 50 局均分、\(\varepsilon\)、回放池大小、死因计数与棋盘快照。观看模式复用同一权重，\(\varepsilon=0\)，约 8 Hz 演示。

命令行自检 `server/train_cli.py` 固定 `grid_size=8`、`seed=1`，用于判断某次算法改动是否跨过预先写下的均分门槛。看板训练不固定种子，并可能从已有权重继续，因此同一算法在 CLI 与 UI 上可以给出不同均分。后文会标明来源。

## 4 迭代实验

每一小节对应一次「假设 → 改动 → 观测 → 诊断」。均分若无说明，均指近 50 局算术平均。

### 4.1 第 0 代：表格 Q 与 11 维特征

**假设。** 只需知道「眼前一格是否危险」和「食物在哪个方向」，表格 Q-learning 就能学会吃豆。

**方法。** 观测为 11 个二进制位：前方 / 左 / 右是否一步致死、四个朝向 one-hot、食物相对上下左右。Q 表 \(Q[s,a]\)，\(\varepsilon\)-greedy，TD 更新。无卷积、无回放。

**结果。** 看板约 5372 局后：均分 **11.96**，\(\varepsilon=0.020\)，Q 状态数 **256**，总步数约 \(4.1\times 10^5\)。命令行自检：前 50 局均分 0.18，后 50 局 **11.92**。

**诊断。** 状态数饱和与均分同时停止，说明不是训练不够，而是**状态混叠**。短蛇畅通去吃豆、与长蛇朝同一方向会把自己围死，被编码成同一个 \(s\)，只能学到一套「躲眼前一格 + 朝食物走」的策略。该策略足以吃到约十几颗；再长必须看见身体形状。8×8 满分 61，均分 12 对应长度约 15，只占棋盘一小块。

**结论。** 下一刀必须换观测，而不是加大学习率或改成 PPO。表格存不下网格，故改为小 DQN。

### 4.2 第 1 代：朝上网格 + 小 DQN

**假设。** 把棋盘编成图像，并旋到「当前朝向朝上」，可使三个相对动作与卷积的空间轴对齐，从而打破混叠。

**方法。** `observe()` 输出 \(3\times 8\times 8\)：头、沿身体衰减的躯干、食物。网络为无 padding 的两层 \(3\times 3\) 卷积（3→16→32）再接到 128 维隐层、3 个 Q。经验回放容量 \(5\times 10^4\)，目标网络，Huber 损失，后来加入 Double DQN（在线网选 \(a'\)，目标网估价值）。\(\gamma=0.97\)，Adam \(10^{-3}\)。\(\varepsilon\) 前 2500 局线性降到 0.01。

**结果。** 命令行 6000 局：后 50 局均分约 **16.28**。看板约 14667 局：均分约 **21**。死因以撞自己为主（约 10173），撞墙约 4493，超时几乎为 0。

**诊断。** 网格观测把天花板从 12 抬到约 21，证实第 0 代的判断。剩余问题是：探索仍大量走进「一步就死」的动作，撞墙数据污染回放；长蛇自撞说明网络尚未学会留活路。感受野在无 padding 时约 5 格，远角口袋看不全，但此时主要矛盾仍是非法动作过多。

### 4.3 第 2 代：一步掩码、死胡同奖励、长蛇停止探索

**假设。** 缩小动作空间、给连通性负奖励、长蛇不再随机走，应同时降低墙死并抬高均分。

**方法。**

1. `legal_actions()`：模拟三动作，一步致死则掩掉；并要求走完后洪水填充格数 \(\ge\) 新长度。
2. 探索与贪心都只在掩码内选择；非法 Q 置为 \(-10^9\)。
3. 连通空格少于 \(2\times\) 蛇长时施加死胡同惩罚（系数 \(-0.6\)）。
4. 分数 \(\ge 10\) 后不再给「靠近食物」的 \(\pm 0.05\)，以免长蛇贴食物贴死。
5. 蛇长 \(\ge 12\) 时训练 \(\varepsilon\) 强制为 0。

**结果。** 仅掩一步死亡时，命令行 6000 局后 50 局均分 **21.22**，撞墙 498 / 撞自己 5369 / 超时 133（门槛均分 \(\ge 24\) 未过，但墙死已远少于自撞）。把「走完空间不够」也写入掩码并加强死胡同后，命令行 **21.76**，撞墙 415 / 自撞 5367 / 超时 218，仍未过 24。

看板在**不重置网络**、接着第 1 代约 21 分权重继续训时：2414 局，均分 **26.48**，\(\varepsilon=0.044\)，撞墙 256 / 自撞 1944 / 超时 214。

**诊断。** 掩码立刻改变失败结构（墙死数量级下降）。从零训的 CLI 仍卡在约 21，说明掩码减少了浪费的搜索，但没有单独教会「长蛇继续吃豆」。UI 的 26 分更像是旧策略加上新约束的叠加，而不是塑形单独把上限抬到 26。超时开始出现，表明有的对局已经能活满步数上限。

此阶段有一个实现缺陷：当三个动作都不满足「安全」条件时，掩码被设为全 `True`，以便对局能结束。该缺陷在第 2 代数据里还不醒目，因为一步死亡掩码已经挡掉大部分撞墙；到第 3 代与摸尾条件合取之后，它会变成墙死的主因。

### 4.4 第 3 代：四通道、padding 卷积、优先回放、摸尾、曼哈顿启发式

**假设。** 若感受野更大、学习时也掩 next Q、回放按 TD 误差优先，并在长度 20 后用规则跟尾，均分应明显超过 21。该改动更换卷积输入通道，**旧 3 通道权重作废**，必须从零训练。

**方法。**

- 观测改为 \(4\times 8\times 8\)：增加从头部出发的可达格通道。
- 三层 \(3\times 3\)、`padding=1` 卷积（4→16→32→32），感受野约 7。
- 转移存 \((s,a,r,s',\mathrm{done},\mathrm{mask},s'\mathrm{mask})\)；Double DQN 选 \(a'\) 前掩非法位。
- 优先经验回放：\(p_i \propto (|{\delta_i}|+\varepsilon)^\alpha\)，\(\alpha=0.6\)，IS 权重 \(\beta\) 从 0.4 升到 1。
- 掩码增加「走完后头还能摸到尾巴」（中间身体为墙，尾巴为终点）。
- 长度 \(\ge 20\) 时 `heuristic_action`：在合法动作里优先曼哈顿靠近食物，否则减小到尾巴的距离。
- 超时惩罚改为 \(-4\)；分数 \(\ge 10\) 的移动步 \(-0.01\)；不吃上限改为 \(4n^2\)。

**结果。** 看板从零训练 10908 局、\(\varepsilon=0.010\)：均分 **21.62**，总步数约 \(2.0\times 10^6\)。死因：撞墙 **2619** / 撞自己 **8247** / 超时 **42**。墙死约占 24%。

**诊断。** 超时被压下去了（idle 惩罚有效），但出现两个倒退。

1. **墙死回升。** 摸尾条件使大量中后盘局面「三个动作都不安全」，触发全 `True` 兜底，探索或启发式默认直行，重新撞墙。掩码在纸面上更严，实际上在最危险的状态被关掉。
2. **启发式弱于旧 DQN。** 长度 20 约等于 17 分，之后规则接手。曼哈顿「更近」会贴食物封死自己，均分仍停在约 21，甚至低于第 2 代接着旧权重得到的 26。失败仍以自撞为主（76%）。

此代还说明：换更大的卷积和 PER，**救不了错误的动作约束**。\(\varepsilon\) 已经到底，再训一万局没有意义。

### 4.5 第 4 代：两层掩码 + 安全 BFS 吃豆 / 跟尾

**假设。** 看板记录中的墙死来自兜底，自撞来自近视启发式。不改卷积、不重置大脑，只改搜索边界与长蛇规则。

**方法。**

1. 掩码两层：先取「一步不致死且能摸尾且空间足够」；若为空，只保留一步不致死（墙与立刻咬身仍为非法）；三者皆死则全 `False`。`DqnAgent.act` 在合法集为空时返回 0，不再扩成 \(\{0,1,2\}\)。
2. 启发式改为经典搜索：空格上 BFS 从头到食物，若第一步对应某相对动作且模拟后仍能摸尾，则走它；否则 BFS 通往尾巴；再否则在一步存活的动作里选连通体积最大者。

**结果。** 短自检通过（贴墙直行保持非法；三面皆死时掩码全 False 且直行不为 True；吃进环心不放开转弯；启发式一步 `simulate` 非空）。从开局即用启发式、12 个种子的探测：分数 \([20,43,20,10,39,51,53,45,31,53,45,16]\)，均分 **35.5**，结束原因**全部为超时**。

看板同一配方、不重置 4 通道网络（权重已写入 `server/models/dqn.pt`）：

| 快照 | 局数 | 近 50 局均分 | \(\varepsilon\) | 总步数 | 撞墙 | 自撞 | 超时 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 刚接上启发式 | 56 | 27.06 | 0.978 | \(5.0\times 10^4\) | 0 | 3 | 53 |
| 继续训 | 793 | **36.34** | 0.686 | \(6.5\times 10^5\) | 4 | 29 | 747 |

793 局时回放已满 \(5\times 10^4\)。平均约 823 步/局。超时占死因 **747/793 ≈ 94%**；早死（墙 + 自己）仅约 4%。\(\varepsilon\) 按 2500 局线性衰减，此时约走过日程的三分之一。

**诊断。** 墙死接近 0，说明第 3 代墙死确由全 `True` 兜底造成。均分在 \(\varepsilon\) 仍高时就超过纯启发式探测的 35.5，说明：长度 \(\ge 12\) 强制贪心使短蛇多数能活到启发式接手，规则再把分数从约 17 抬到 30+。新的失败模式是**活满「256 步不吃」却找不到豆**——跟尾保命，吃豆 BFS 在身体约占四成棋盘时经常判「走过去会摸不到尾巴」，于是空转直到超时。

继续把 \(\varepsilon\) 降到 0.01 最多再减少那 4% 的早死，回放会继续被绕圈轨迹占满。故第 4 代在均分约 36、超时主导时应**暂停并保存**，而不是再挂到 2500 局指望均分到 50。下一刀是超时上限或跟尾时的安全取食（哈密顿捷径），不是更多梯度步。

## 6 讨论

### 6.1 强化学习在这里主要是什么

可以把一局拆成三层搜索：环境里选动作；用 TD 把经验压进 \(Q\)；用卷积把未见过的棋盘接到见过的棋盘。第 0 代失败在第三层（表示）；第 2–4 代的有效改动几乎都在第一层（合法动作与启发式）。贝尔曼更新（第 1 代引入的 DQN）是必要的，但在表示与动作空间错误时，梯度多打在「撞墙很疼」上。

这与近年来大模型后训练的经验同构：底座（预训练 / 网格 \(Q\)）提供能力上限，可验证的环境与约束（单测 / 掩码 / 摸尾）决定 pass@1 能否把已有能力采出来。蛇的「可验证奖励」就是碰撞与吃豆；掩码是把非法轨迹从采样分布里删掉。

### 6.2 为何不在后期改用 PPO 或 GRPO

PPO 将策略变成 \(\pi_\theta(a|s)\) 并用优势（常配合 GAE）更新，不维护 \(Q\) 表，且通常丢弃大规模回放。本任务动作 3 个、转移确定、失败可逐步诊断。第 3 代已经证明：把活路判定写错，任何 on-policy 方法也会在自撞上失败，同时还更难在 CPU 上稳定训练。GRPO 面向「同一提示采样一组完整回答再组内比较」，不对应逐步 MDP。故全文保持 DQN。长度 ≥ 20 的规则策略是承认：通关 8×8 的标准解是几何搜索，不是更好的优势估计。

### 6.3 塑形的边界

靠近食物的奖励在短蛇阶段加速学习，在长蛇阶段制造「贴死」。死胡同惩罚与 idle 惩罚改变的是超时比例，不自动提高吃豆数。第 3 代超时 42/10908，第 4 代早期 53/56、至 793 局为 **747/793**，是同一枚硬币的两面：越会活，越容易活到「不吃就判负」的上限。超时 \(-4\) 轻于撞死 \(-10\)，避免把空转等同于撞墙，但也使跟尾满足于保命。

### 6.4 局限

- 看板数字无固定种子，且加载权重不恢复局数与 \(\varepsilon\) 日程，故第 4 代 56 局的 27 分、793 局的 36 分不可与第 3 代 10908 局的 21 分做严格的同预算比较。793 局时 \(\varepsilon\) 尚未到底，均分已贴近（并略超过）纯启发式探测，说明继续训的边际主要在短蛇稳定性。
- 第 4 代启发式在探测与看板上均以超时为主，说明规则仍不会在高占用率下安全取食；未实现哈密顿环或「沿尾巴的哈密顿捷径」。
- 未做消融：未单独关闭 PER、第四通道或 Double DQN 来定量各自贡献。第 3 代从零训未超过第 1–2 代，已经提示这些部件不是当时的主因。
- 人玩 10×10 不走 DQN，结论不可外推到更大棋盘。

---

## 7 结论

在 8×8 贪吃蛇上，把强化学习写成「带回报的搜索」比写成「换一个带 GAE 的算法」更有预测力。迭代顺序是：

1. 用网格观测打破 11 维混叠，均分从约 12 到约 21；
2. 用动作掩码删除一步死亡，墙死下降一个数量级；
3. 错误的「全非法则全合法」会把墙死送回来；两层掩码使其归零；
4. 长蛇必须显式留活路。曼哈顿启发式不够，安全 BFS 吃豆加跟尾把失败模式改成超时；看板 793 局均分 **36.34**（超时约 94%），探测约 35。

当前系统的上限不再是 \(\varepsilon\) 或回放容量，而是：**在身体占据约四成棋盘时，如何在不失去尾巴通路的前提下吃到下一颗豆。** 这是搜索与棋盘几何的问题。第 4 代在均分约 36、超时主导时即可停止猛训。可能的下一步是加长不吃上限、在跟尾循环上检测食物捷径，或在偶数宽棋盘上嵌入哈密顿环；它们都不必更换 PPO。
